# Экология и общественный экологический контроль

## Начать с классификации, а не с названия ведомства

- Вода: загрязнение, сброс, изменение русла, водоохранная зона, нарушение использования береговой полосы. Определить статус водного объекта, местоположение источника, характер использования, владельца объекта (если установлен).
- Отходы: место образования, контейнерная площадка, региональный оператор, несанкционированное размещение, строительный мусор; эти случаи имеют разных ответственных.
- Воздух/запахи: время, повторяемость, предполагаемый источник; не выводить концентрации по запаху и не утверждать превышение без измерений.
- Рубки и насаждения: земли лесного фонда, городские зелёные насаждения, ООПТ, частный участок — разные правовые режимы.
- Объект негативного воздействия: уточнить категорию НВОС и федеральный/региональный контур надзора, изучить реестр и применимые критерии.
- Общественная инициатива: субботник, просвещение, благоустройство, общественная инспекция — не всякая задача требует надзорной жалобы.

## Доказательства и границы вывода

Фиксировать GPS/адрес, дату, способ наблюдения, фотографии с ориентирами, границы объекта; при экологических измерениях — методику, прибор, лабораторию, дату и неопределённость. Разделять «вода выглядит мутной» и «установлено загрязнение веществом X». Не публиковать чужие личные данные.

## Адресаты — только после статуса объекта

Проверить компетенции Росприроднадзора, регионального экологического органа, Рослесхоза/лесного надзора, муниципалитета, Роспотребнадзора, органов водного хозяйства и иных органов по конкретному эпизоду. Нет универсального адресата «Росприроднадзор» для всех эковопросов.

## Контрольный механизм

Различать обращение по 59-ФЗ и сведения для государственного контроля по 248-ФЗ; для второго проверить идентификацию и основания действий надзорного органа. Отправка сообщения не обязывает автоматически выйти с внеплановой проверкой. Запросить результат и доступные акты/решения, а затем проверить фактическое устранение.

## Примеры задач

Для заброшенной рекреационной территории отдельно выясни статус земли, имущественные решения, требования охраны природы и планы благоустройства. При подозрении на сброс в водоём запроси обследование. Если жители готовы убрать мусор сами, согласуй вывоз с ответственным оператором.

## Первичные источники для актуализации

- 7-ФЗ «Об охране окружающей среды», 89-ФЗ «Об отходах производства и потребления», Водный кодекс, Лесной кодекс, 248-ФЗ — сверять действующую редакцию на официальном портале правовой информации: https://pravo.gov.ru/
- Росприроднадзор: https://rpn.gov.ru/
- Роспотребнадзор: https://rospotrebnadzor.ru/
- Росреестр/публичные сведения о земле: https://rosreestr.gov.ru/
