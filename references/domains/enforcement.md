# Прокуратура, МВД, СК и специальные процедуры

## Сначала определить тип материала

Обычное обращение; сообщение об административном нарушении; заявление о преступлении; жалоба участника процесса; прокурорская проверка; сведения для контрольного органа по 248-ФЗ — разные процедуры и сроки.

## Минимальные проверки

- Сообщить факты, источники, время, место, ссылки; отделить возможную квалификацию от установленной.
- Уточнить документальный статус: дата/номер регистрации, КУСП при применимости, процессуальное решение, передача по подследственности, компетентный орган.
- Не требовать раскрытия охраняемых следственных материалов без правового основания.
- Не смешивать дело СК по публичному сообщению с параллельно отправленным заявлением в МВД; соединение веток должно быть подтверждено.
- Не считать прокурорское представление равнозначным физическому демонтажу, а внесение представления — установленной датой окончания работ.

## Надзор по 248-ФЗ

При жалобах на вред/угрозу вреда проверить статью 59 и способ идентификации заявителя; правила контрольных мероприятий не сводятся к 59-ФЗ. Не обещать обязательную внеплановую проверку в ответ на обращение.

## Параллельные производства

Если один эпизод рассматривают несколько органов или обращение охватывает разные события, веди отдельные записи по каждому эпизоду и адресату. Указывай процессуальный статус только по относящимся к нему документам.
